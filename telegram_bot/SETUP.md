# Настройка телеграм-бота Sofia Coffee

## Пошаговая инструкция

### 1. Создание бота в Telegram

1. Откройте Telegram и найдите [@BotFather](https://t.me/botfather)
2. Отправьте команду `/newbot`
3. Введите имя для вашего бота (например: "Sofia Coffee Bot")
4. Введите username для бота (например: "sofia_coffee_bot")
5. **Сохраните полученный токен!** Он выглядит примерно так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

### 2. Настройка токена

Создайте файл `.env` в корневой директории проекта (рядом с `manage.py`) со следующим содержимым:

```env
TELEGRAM_BOT_TOKEN=ваш_токен_здесь
```

**Пример:**
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 3. Запуск бота

```bash
python telegram_bot/run_bot.py
```

### 4. Тестирование

1. Найдите вашего бота в Telegram по username
2. Отправьте команду `/start`
3. Попробуйте команды:
   - `/menu` - посмотреть меню
   - `/cart` - посмотреть корзину
   - `/help` - справка

## Возможные проблемы

### Ошибка "Token is invalid!"
- Проверьте, что токен скопирован полностью
- Убедитесь, что в токене нет лишних пробелов
- Токен должен начинаться с цифр и содержать двоеточие

### Ошибка "Token is not set!"
- Убедитесь, что файл `.env` создан в правильной директории
- Проверьте, что в файле `.env` есть строка с токеном
- Перезапустите бота после изменения `.env`

### Бот не отвечает
- Проверьте, что бот запущен без ошибок
- Убедитесь, что Django-сервер работает (для доступа к базе данных)
- Проверьте интернет-соединение

## Команды бота

- `/start` - Начать работу
- `/menu` - Показать меню товаров
- `/cart` - Показать корзину
- `/order` - Оформить заказ
- `/help` - Показать справку

## Структура файлов

```
sofia/
├── .env                    # Файл с токеном (создать вручную)
├── telegram_bot/
│   ├── bot.py            # Основная логика бота
│   ├── run_bot.py       # Скрипт запуска
│   └── SETUP.md         # Эта инструкция
└── ...
```

## Безопасность

⚠️ **Важно:** Никогда не публикуйте файл `.env` в публичных репозиториях!

Добавьте `.env` в `.gitignore`:
```
.env
```

## Дополнительные настройки

В файле `.env` можно также указать:

```env
TELEGRAM_BOT_TOKEN=ваш_токен
WEBHOOK_URL=https://your-domain.com/webhook/
DEBUG=True
```
