# Sofia Coffee Shop

Веб-приложение кофейни Sofia Coffee с интеграцией телеграм-бота.

## Функциональность

### Веб-приложение
- 📋 Каталог товаров с категориями
- 🛒 Корзина покупок
- 📝 Оформление заказов
- 📰 Новости и промо-акции
- ⭐ Отзывы клиентов
- 🎯 Рекомендации товаров
- 👨‍💼 Админ-панель Django

### Телеграм-бот
- 📱 Просмотр меню в Telegram
- 🛒 Добавление товаров в корзину
- ✅ Оформление заказов через бота
- 💬 Интерактивный интерфейс

## Установка и запуск

### 1. Клонирование и установка зависимостей

```bash
git clone <repository-url>
cd sofia
pip install -r requirements.txt
```

### 2. Настройка базы данных

```bash
python manage.py migrate
python manage.py createsuperuser
```

### 3. Запуск веб-сервера

```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000/

### 4. Настройка телеграм-бота

1. Создайте бота через [@BotFather](https://t.me/botfather)
2. Создайте файл `.env` на основе `.env.example`
3. Добавьте токен бота в `.env`
4. Запустите бота:

```bash
python telegram_bot/run_bot.py
```

## Модели данных

- **Category** - Категории товаров
- **Product** - Товары
- **Order** - Заказы
- **OrderItem** - Позиции заказов
- **Cart** - Корзина (модель для админки)
- **Promo** - Промо-акции
- **News** - Новости
- **Review** - Отзывы клиентов
- **Recommendation** - Рекомендации товаров

## URL маршруты

- `/` - Главная страница
- `/menu/` - Меню товаров
- `/cart/` - Корзина
- `/order/` - Оформление заказа
- `/promo/` - Промо-акции
- `/news/` - Новости
- `/reviews/` - Отзывы
- `/recommendations/` - Рекомендации

## Технологии

- **Backend**: Django 5.2
- **Database**: SQLite (по умолчанию)
- **Frontend**: HTML, CSS, JavaScript
- **Bot**: aiogram 3.x
- **Images**: Pillow

## Разработка

### Добавление новых товаров

1. Войдите в админ-панель: http://127.0.0.1:8000/admin/
2. Добавьте категории в разделе "Категории"
3. Добавьте товары в разделе "Товары"

### Настройка бота

Подробная документация по настройке и использованию бота находится в `telegram_bot/README.md`.
